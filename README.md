## GoIT: Homework 4

In this homework, the task was to continue developing the CLI bot that I worked on in previous homeworks. It had to have further functionalities:

- Create a contact book system using OOP principles to easily add, find, and delete contacts by their name.
- Make contact fields flexible so that the name is required, but users can add, change, or remove multiple phone numbers for one person.
- Add validation for phone numbers to ensure they consist of exactly 10 digits.

Technology used - Python
