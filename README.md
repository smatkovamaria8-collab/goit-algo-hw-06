GoIT: Homework 4
In this homework, the task was to continue developing the CLI bot that I worked on in previous homeworks. It had to have further functionalities:

- Create a contact book system using OOP principles to easily add, edit, and delete contacts.
- Make contact fields flexible so that the name is required, but users can add, change, or remove multiple phone numbers and emails for one person.
- Build a smart search feature to find contacts by name, phone, or email using partial matches.

Technology used - Python
